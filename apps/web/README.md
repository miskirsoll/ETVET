# ETVET Studio (web)

Next.js 16 (App Router) frontend for the ETVET platform — course authoring
now, live interactive sessions in a later phase. See `../../PLANNING.md` at
the repo root for the full build plan and architecture decisions.

## Setup

1. Create a [Supabase](https://supabase.com) project.
2. Apply the migrations in `../../supabase/migrations/` (via `supabase db
   push`, the Supabase CLI, or by pasting them into the SQL Editor, in
   order).
3. Copy `.env.local.example` to `.env.local` and fill in your project's URL
   and anon key from Project Settings → API.
4. `npm install && npm run dev`, then open http://localhost:3000.

Signing up creates a new organization (FREE tier, you as ORG_ADMIN) via a
database trigger — see `0002_signup_trigger.sql`. Use `/upgrade` to flip
your org between FREE/PRO/MAXPRO for testing; this updates
`subscription_tier` directly since Stripe isn't wired yet, but every
`requireTier()` check downstream works off that same field.

## Notes for future work in this app

- **This is Next.js 16, not the Next.js in most training data or older
  tutorials.** `middleware.ts` is renamed to `proxy.ts` (exported function
  is named `proxy`, not `middleware`), and several APIs changed. Read
  `node_modules/next/dist/docs/` before assuming an older convention still
  applies — `AGENTS.md` at this app's root has the same reminder and is
  regenerated by `next dev`.
- Course authoring (`/studio`) is gated at `requireTier("PRO")`; Live
  Sessions (`/studio/live`) is gated at `requireTier("MAXPRO")` and uses
  `<LockedFeature>` to stay visible-but-locked for PRO orgs rather than
  hidden, per the spec's explicit UX rule.
- Quiz Lesson content editing, SCORM export, and everything in Module B/C
  are intentionally not built yet — see the build order in
  `../../PLANNING.md`.
